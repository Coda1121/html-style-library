# HTML 風格靈感庫

2026 網頁設計風格、配色與字體的靈感庫，供撰寫「轉成 HTML」的 prompt 時參考。

線上版：https://coda1121.github.io/html-style-library/

## 內容

- 49 種設計風格，分成七類，可依分類、熱度、色調、適合情境篩選
- 18 組色彩風格，附色碼與 CSS 變數
- 12 組字體搭配，皆可從 Google Fonts 載入
- 每個風格都有樣式預覽、prompt 關鍵字，以及可直接貼給 AI 的一段話 prompt
